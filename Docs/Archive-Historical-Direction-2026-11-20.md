# 历史方向归档（2026-11-20）

> 本文件归档自根目录 `AGENTS.md` 的早期产品与商业方向记录。
> 当前方向已于 2026-11-23 调整为**海外竖屏 3D 军团手游（计划验证 IAP）**，下列网页 / CrazyGames / 抖音小游戏 /《拆机救主板》条目仅作历史参考，不覆盖 `AGENTS.md` 中的现行规则。

## 原文记录（2026-11-20）

- 首要目标是尽快验证赚钱机会，并争取持续的小额收入；首个商业目标为每月几百元（扣除平台分成和直接运营成本后、个人税费前）。这是目标，不是收益承诺，不能把单次收入或未结算余额当成目标已达成。
- 现金投入尽量为零。所需 Asset Store 插件或资源可列出具体需求，由用户协助提供，这部分暂不计入现金预算；上架、服务器、推广等开支仍需单独评估，未经授权不付费。
- 时间灵活，但应尽快推进；控制原型范围，避免长期准备而没有可玩的成果。
- 国内海外均可考虑；用户愿意本人办理必要的账号注册、身份认证和收款设置。
- 已接受的发行策略：以轻量 Unity 网页游戏为产品基线，以 CrazyGames 为首轮主要市场测试目标，后续争取广告变现；同时提前核实抖音小游戏准入与适配条件。抖音不是已经确定的首发平台。
- 不并行维护多个完整发行版本；先制作一个核心玩法。具体发行前核查当时的平台政策、收款资格、合作与独占条款。
- 首个市场测试版本优先保证电脑浏览器体验，操作设计保留触屏适配空间；首轮不要求同时完成手机适配。
- 玩法类型不限，2D / 3D 均可。由智能体结合商业机会、渠道适配、开发与维护成本、素材条件筛选和决定原型方案，主动研究、实施并用结果验证，不把日常策划选择逐项交回用户。
- 当前最新研究重点是面向抖音小游戏的获客、传播与广告变现，优先验证《拆机救主板》所属的可视化短关卡解谜方向。上述早期网页 / CrazyGames 路线保留为历史基线和发行候选，不能替代对抖音手机触屏体验及真实用户的验证；不得宣称尚未验证的玩法已证明能赚钱。
- 智能体承担项目推进与日常策划职责，主导调研、玩法规则、操作、关卡、难度、原型范围、架构、程序、美术资源接入、MCP 与运行验证；用户主要审阅成果、试玩反馈，并在必要阻塞时提供协助。
- 测试与推广材料由智能体准备；用户愿意配合使用自己的账号发布或转发内容，并邀请玩家试玩。未经明确指示不代用户向外发送或发布内容。
